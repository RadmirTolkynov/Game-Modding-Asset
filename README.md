# Game Modding & Asset 

Веб-платформа для публикации, обмена и управления игровыми модификациями, кастомными текстурами, ливреями и аудио-паками.

## Стек технологий
* Frontend: Django Templates, Tailwind CSS (v4)
* Backend: Python, Django REST Framework (DRF)
* Database: SQLite / PostgreSQL

## Архитектура базы данных 
1. Game — содержит информацию о поддерживаемых играх (Название, жанр, платформа).
2. Asset — основная сущность мода или текстуры. Хранит описание, файлы, ссылку на `Game` и автора (`request.user`).
3. Review  — система обратной связи от пользователей (Рейтинг, текст комментария, связь с конкретным `Asset`).
4. DownloadLog — логирование скачиваний для аналитики бэкенда и API (Связь с `User` и `Asset`).
